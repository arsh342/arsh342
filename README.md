# arsh

Just a guy creating things, learning as I go, and trying to make software that feels great to use.

## Fun Facts

- I build Mac apps and Blender add-ons, because picking one thing is hard
- I'm building a VM manager for the Mac in Swift and C

## Things I Made

- [openVM](https://github.com/arsh342/openvm): run Windows and Linux on your Apple Silicon Mac, connected to macOS
- [OpenSimFX](https://github.com/opensimfx): Blender add-ons for cinematics, at [opensimfx.in](https://www.opensimfx.in)
  - [BlastFX](https://github.com/opensimfx/blastfx): procedural cinematic explosions
  - [AtmosFX](https://github.com/opensimfx/atomsfx): a complete sky and atmosphere in one click
  - [RainFX](https://github.com/opensimfx/rainfx): physically based weather, from drizzle to snow
  - [FlowFX](https://github.com/opensimfx/flowfx): water simulation, from still ponds to tsunamis
- [TextGrab](https://github.com/arsh342/TextGrab): grab text from anywhere on your Mac's screen
