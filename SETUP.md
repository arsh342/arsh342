# arsh342 GitHub Profile

A terminal-style profile README with light/dark mode and automatically updated GitHub statistics.

## Structure

- `README.md` — embeds the profile SVG
- `today.py` — retrieves GitHub statistics through GraphQL
- `assets/` — SVG templates
- `light_mode.svg` / `dark_mode.svg` — generated profile images
- `.github/workflows/update-profile.yml` — daily and manual updates

The profile intentionally has no photo or image placeholder.
